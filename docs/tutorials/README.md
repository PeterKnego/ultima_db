# Tutorials

A tutorial is a lesson: you follow along, everything works, and you come out
the other side having built something real. Start here if UltimaDB is new to
you — no prior knowledge of the engine is assumed beyond working Rust.

[**Getting started: build a task tracker**](getting-started.md) — create a
store, write and read typed records in transactions, look back into the
store's version history, and query through a secondary index. About fifteen
minutes, entirely in memory, verified end to end.

When you finish, the [how-to guides](../how-to/README.md) pick up where the
tutorial stops — starting with
[keeping your data across restarts](../how-to/set-up-durable-persistence.md).
